# Vocabulary that must not appear under src/ in this library.
#
# The library carries no knowledge of any product built on it. This list makes that
# checkable instead of aspirational: acceptance criterion AC4 in the extraction spec greps
# src/ for these terms, whole-word and case-insensitive, and fails on any match.
#
# Two rules for maintaining it:
#   - A term joins this list when a product concept is found leaking, not pre-emptively.
#   - A term leaves it only when the concept genuinely becomes general, with a note saying so.
#
# Blank lines and lines beginning with # are ignored by the check.

ronna
lightspeed

# Block kinds belonging to a consumer, not to the runtime
tool_activity
search_result
search_complete

# Stay-behind subsystems the runtime must never name
deno

tauri
sandbox
worktree
skill
proxy

serper
langsearch

projects.json
code_execution
